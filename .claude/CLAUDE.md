# clanker_blender

Collection of QoL Blender add-ons (extension format) in `addons/<id>/`. Target Blender 5.2 LTS
(Steam: `~/.local/share/Steam/steamapps/common/Blender/blender`). User wants every change pushed
straight to `main`.

- Test: `./scripts/test.sh [id]` (headless, factory settings, registers addons/ as repo "clanker").
- Conventions: `docs/ADDON_GUIDE.md`.

## Project memory
- .claude/notes/preferences.md: how the user wants work done here
- .claude/notes/errors.md: fixed errors and gotchas
- docs/ADDON_GUIDE.md: add-on conventions + Blender 5.x API gotchas
- docs/IDEAS.md: backlog of QoL ideas with status
