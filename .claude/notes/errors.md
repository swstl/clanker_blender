# Errors

- **`blender --command extension ...` loads all user add-ons**: put `--background --factory-startup` before `--command`. (2026-11-04)
- **Bash call with `ls -R` at end hung >120s**: `ls` is aliased (eza); avoid `ls -R` in scripts. (2026-11-04)
- **`object.vertex_group_clean` / `vertex_group_limit_total` ignore `temp_override(object=...)`**: they act on view-layer-selected objects only (silent no-op otherwise). `normalize_all` and `quantize` respect the override. Weight paint brush weight lives at `tool_settings.weight_paint.unified_paint_settings.weight` (5.x, no `tool_settings.unified_paint_settings`). (2026-11-04)
- **`ShaderNodeMix.inputs["A"]` returns the hidden Float socket** even with `data_type='RGBA'`: look up by identifier (`A_Color`, `B_Color`, `Result_Color`). New materials already have a node tree in 5.x (`use_nodes` deprecated). (2026-11-04)
- **`view_layer.objects` yields `None` right after `bpy.data.objects.remove()`** (stale until a view-layer update), e.g. in tests after `run.py` clean(): iterate `bpy.data.objects` / `scene.objects` instead. Draw callbacks can be smoke-tested headless with `gpu.init()` + `with gpu.types.GPUOffScreen(64,64).bind(): draw()`. (2026-11-04)
- **Geometry-nodes modifier inputs are no longer IDProperties (5.2)**: `md["Input_1"]` raises TypeError; use `md.properties.inputs.Input_1.value` (identifier = interface socket identifier). `object.modifier_copy_to_selected` honors `temp_override(selected_editable_objects=...)` and copies pointers + GN inputs. (2026-11-04)
- **`ReferenceError: BMesh data of type BMVert has been removed`**: `ordered(bmesh.from_edit_mesh(me))` lets the BMesh wrapper be garbage-collected while its verts are still used; keep `bm` in a variable. (2026-11-04)
- **Bone rename via RNA (`bone.name`/`edit_bone.name`) already renames vertex groups on meshes with an Armature modifier, constraint subtargets, driver bone targets and F-Curve paths** (verified 5.2.3); no manual vgroup fixup needed. `EditBone.select*` still exists in 5.x; `Bone.select` is gone (use `PoseBone.select`). (2026-11-04)
- **`wm.keyconfigs.default` is empty in `--background`** (keymaps only built with a window): to check default-key conflicts, `sys.path.insert(0, bpy.utils.preset_paths("keyconfig/keymap_data")[0]); import blender_default as bd; bd.generate_keymaps(bd.Params())` and scan the `(op, event, props)` items. (2026-11-04)
- **`PoseBone.constraints` has no `.clear()`** (5.2): remove one by one over `list(pb.constraints)`. Visual bone transform -> basis: `ob.convert_space(pose_bone=pb, matrix=pb.matrix, from_space="POSE", to_space="LOCAL")` after `scene.frame_set(f)` works headless. (2026-11-04)
- **`ob.material_slots` length lags after `ob.data.materials.pop()`** (loop on it -> "Index out of range"): use `len(ob.data.materials)`. `bmesh.ops.create_grid/cube(calc_uvs=True)` silently skips UVs unless `bm.loops.layers.uv.new()` exists first. Selecting faces with `f.select_set(f in bad)` in one pass deselects shared verts of bad faces: deselect all first. ID custom props can't be lists with `None`; use a dict `{"0": mat}` (holds a user). 5.x has native `uv.select_by_winding`. (2026-11-04)
- **Cycles bake tests: image mean includes unbaked background** (cube UVs cover ~65% of 0-1, bake leaves alpha=1 black outside islands); test on a plane (full 0-1 UVs). ROUGHNESS pass returns the raw socket value; Base Color/Metallic/Alpha need the Emission rewire + EMIT trick. `MeshUVLoopLayer` refs go stale after `mode_set`: re-fetch by name. (2026-11-04)
- Parenting via `child.matrix_world = mw` right after creating/moving the parent: call `view_layer.update()` first, the parent's matrix_world is stale until then. (2026-11-04)
- **File Output node (5.x)**: inputs come from `node.file_output_items.new(socket_type, name)`; socket_type is `FLOAT` not `VALUE` (Render Layers outputs report `VALUE`). Inputs follow item order plus a trailing `__extend__` socket. Item name with `/` = sub-path (`Depth/Depth_` -> `Depth/Depth_.png`); multilayer = `format.media_type = 'MULTI_LAYER_IMAGE'`. `file_name` supports native templates like `{scene_name}`. Render Layers outputs exist only for enabled passes; Emission socket is "Emission". (2026-11-04)
- **VSE strip moved via `content_start` into another strip is silently shuffled to a free channel** (and stays there when moved back): move strips in an order that never overlaps (ascending when shifting left, descending right). Effect strips with inputs have read-only `content_start` (they follow inputs); removing an input strip also removes its effects. Native `sequencer.*` ops (gap_insert, set_range_to_strips, select_grouped) fail poll headless; `context.sequencer_scene` is None in --background. (2026-11-04)
- **`bpy.ops.rigidbody.world_remove()` leaves the "RigidBodyWorld" collection behind** (created lazily by `rigidbody.object_add`); remove it yourself if you created the world. Rigid body and cloth both simulate headless only when stepping `scene.frame_set()` frame by frame from the point cache start; original `ob.matrix_world` then holds the simulated transform. (2026-11-04)
- **Native sculpt operators (`paint.mask_flood_fill`, `sculpt.mask_filter`, `sculpt.face_sets_init`) segfault in `--background`** even with a VIEW_3D area/region override (5.2.3). `object.mode_set(mode='SCULPT')` works; test by writing `.sculpt_mask` (float POINT) / `.sculpt_face_set` (int FACE) attributes in Object Mode, then toggle back to Sculpt. Parallel agents share the scratchpad dir: use a subfolder per add-on. (2026-11-04)
